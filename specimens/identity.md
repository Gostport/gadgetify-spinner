IDENTITY = {
    archetype       : dominant_persona_or_form(S),
    symbols         : 8..16 culturally meaningful symbols(S),
    places          : 2..5 relevant environments_or_landmarks(S),
    objects         : 4..10 iconic objects(S),
    achievements    : 3..7 defining ideas/events(S),
    tensions        : opposing forces / contradictions(S),
    physical_anchor : one ordinary real-world object that can
                      metaphorically represent S,
    title           : shortest recognizable name(S),
    motto           : infer_concise_phrase(S)
}

// 02 — BUILD THE MONUMENTAL TOTEM

Create ONE tall frontal figure/silhouette representing S.

The silhouette must read instantly from a distance.

Divide vertically:

        HEAD
          ↓
    IDEAS / MIND
          ↓
      IDENTITY
          ↓
      ACHIEVEMENTS
          ↓
      PLACE / ROOTS
          ↓
       LEGACY

But do NOT use literal labeled boxes.

Instead fill the body with a dense symbolic collage.

Example transformation:

portrait.face
    → angular mask / emblem

torso
    → architecture + books + diagrams + machines

arms
    → tools / actions / symbols

lower body
    → landscapes / crowds / infrastructure / history

base
    → strongest legacy symbol

// 03 — PHYSICAL-OBJECT BREACH

Introduce ONE unexpected tangible object derived from
IDENTITY.physical_anchor.

It should break out of the otherwise flat poster.

Examples of behavior:

real feather inserted into drawn history
real key crossing an illustrated body
real lightbulb replacing a drawn sun
real thread connecting symbolic regions
real leaf emerging from printed architecture
real ruler crossing a scientific composition
real folded paper object projecting outward

RULE:

only ONE physical intrusion.

Everything else remains printed / illustrated.

The physical object must have semantic meaning,
not merely decoration.

// 04 — ENGINEERED TYPOGRAPHY

Set IDENTITY.title beneath or beside the figure.

Typography is custom-built from subject logic.

Each letter may inherit:

    trajectories
    architecture
    tools
    machines
    anatomical forms
    landscape contours
    scientific diagrams
    cultural ornaments

Do not use a normal font unchanged.

Example:

if S = aviation:
    letter stems → wings / fuselage geometry

if S = music:
    counters → sound waves / strings

if S = astronomy:
    crossbars → orbital paths

if S = architecture:
    letter skeleton → structural beams

if S = biology:
    curves → cellular / botanical structures
