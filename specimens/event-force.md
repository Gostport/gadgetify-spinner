// FIRST PRINCIPLE

DO NOT illustrate {{TOPIC}} next to its name.

BUILD {{TOPIC}} INSIDE ITS NAME.

WORD becomes:

    landscape
    architecture
    timeline
    diagram
    stage
    machine

simultaneously.

// GLYPH STRUCTURE

Construct WORD in enormous condensed black capitals.

Each glyph is treated as architectural volume.

Within / through the letters:

roads may travel
crowds may gather
objects may protrude
walls may crack
machines may operate
buildings may rise
waves may flow
aircraft may cross
figures may climb
landmarks may replace strokes

// EVENT SIMULATION

Convert E1 into a physical force acting on typography.

EVENT_FORCE = map(E1)

Examples:

explosion      → radial fracture
discovery      → reveal / aperture
revolution     → letters overturn
expansion      → glyphs stretch outward
collapse       → broken baseline
flight         → aerodynamic crossing
migration      → repeated figures traverse letters
invention      → mechanical assembly
war            → impact scars / division
unification    → disconnected glyphs interlock
digitalization → modular pixel fragmentation

The event must alter letter geometry.

// HERO OBJECT

ICON is rendered as a small three-dimensional object
or miniature physical model.

It intersects the typography rather than floating outside.

Possible placements:

inside counter
crossing stroke
balanced on baseline
emerging through fracture
replacing letter segment
casting shadow over type

// IDENTITY MANUAL LAYER

Around WORD place a rigorous corporate design-sheet system.

Include only meaningful construction information:

    cap height
    glyph width
    angle
    trajectory
    timeline
    radial origin
    structural axis
    relevant dimensions

Use arrows and engineering labels.

Example:

        1969
          ↓
   ╭────────────────────╮
   │     A P O L L O    │
   │      ↑       ↗     │
   │ LANDER   trajectory│
   ╰────────────────────╯

Do not overload.

Approximately 6–14 annotations.

// HISTORICAL MICRO-TIMELINE

Along one edge place 3–6 tiny dates or stages.

Example grammar:

ORIGIN ─── DEVELOPMENT ─── BREAKTHROUGH ─── LEGACY

But replace these with actual subject-specific events.

Typography:
    tiny technical grotesk.

// SUBJECT-SPECIFIC GLYPH MUTATION

for glyph in WORD:

    if glyph resembles subject object:
        mutate(glyph, subject_object)

    if event trajectory crosses glyph:
        carve_path(glyph)

    if architecture is relevant:
        extrude_into_building(glyph)

        fracture(glyph)

        extend(glyph)

    if movement is relevant:
        shear(glyph)

Maintain minimum 85% word readability.
