// PRIMARY RULE

THE PHYSICAL OBJECT IS REAL.

THE WORLD AROUND IT IS DRAWN.

No other element may compete photographically.

R = photoreal(anchor)

D = hand_drawn_world(subject)

IMAGE = R ∪ D

where:

R ≈ 10–30% of composition
D ≈ 70–90%
